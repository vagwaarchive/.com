# সংগ্রহশালা — GitHub Pages ভার্সন

## ফাইল কী কী
- `index.html` — পাবলিক সাইট, `data.json` থেকে পড়ে লিস্ট আর ডিটেইল দেখায়
- `data.json` — সব এন্ট্রির ডেটা (শিরোনাম, লেখা, লিংক, ছবির URL)
- `admin.html` — শুধু নিজের কম্পিউটারে খুলে নতুন এন্ট্রির জন্য JSON বানানোর টুল (পাবলিশ করার দরকার নেই)
- `images/` — চাইলে এখানে ছবি রাখতে পারো

## GitHub-এ বসানো
1. GitHub-এ একটা নতুন রিপো বানাও (যেমন `my-archive`)
2. এই ৪টা ফাইল/ফোল্ডার রিপোতে আপলোড করো
3. রিপোর **Settings → Pages**-এ গিয়ে Source হিসেবে `main` ব্রাঞ্চ, `/ (root)` ফোল্ডার সিলেক্ট করে Save করো
4. কিছুক্ষণ পর `https://<তোমার-ইউজারনেম>.github.io/my-archive/` লিংকে সাইটটা লাইভ হয়ে যাবে

## নতুন এন্ট্রি যোগ করার নিয়ম
1. কম্পিউটারে `admin.html` ডাবল-ক্লিক করে ব্রাউজারে খোলো
2. ফর্ম পূরণ করো — শিরোনাম, বিবরণ, ছবির লিংক, অন্যান্য লিংক
3. "JSON তৈরি করো" চাপো, তারপর "কপি করো"
4. GitHub-এ গিয়ে `data.json` এডিট করো (পেন্সিল আইকনে ক্লিক), অ্যারের `[` এর ঠিক পরে কপি করা ব্লকটা পেস্ট করো
5. নিচে "Commit changes" চাপো — কিছুক্ষণ পর সাইটে নতুন এন্ট্রি দেখা যাবে

## ছবি রাখার নিয়ম
সবচেয়ে সহজ ও নির্ভরযোগ্য উপায়: এই রিপোর `images/` ফোল্ডারে ছবি আপলোড করো (GitHub-এর ওয়েব ইন্টারফেস থেকেই করা যায়),
তারপর `data.json`-এ লিংক হিসেবে লেখো `images/photo1.jpg`।

গুগল ড্রাইভ ব্যবহার করতে চাইলে সাধারণ শেয়ার লিংক (`.../file/d/FILE_ID/view`) সরাসরি কাজ করবে না।
ফাইল আইডি বের করে এই ফরম্যাটে লিংক বানাও:
```
https://drive.google.com/uc?export=view&id=FILE_ID
```
ড্রাইভের শেয়ারিং সেটিংসে "Anyone with the link" চালু রাখতে হবে, নইলে ছবি দেখাবে না।

## এটা কীভাবে কাজ করে (ডাটাবেজ ছাড়া)
কোনো সার্ভার বা ডাটাবেজ নেই। `index.html` শুধু `data.json` ফাইলটা fetch করে ব্রাউজারে রেন্ডার করে।
নতুন এন্ট্রি মানে `data.json` ফাইলটা এডিট করে GitHub-এ কমিট করা — এতটুকুই।

## যোগাযোগকারীদের কাছ থেকে মেইলে কী ফরম্যাটে ডেটা চাইবে
এই ফরম্যাটটা মেইলের সাইটে দেওয়া ঠিকানায় পাঠাতে বলো:

```
শিরোনাম: পুরোনো বাড়ির ছবি
বিবরণ: এটা আমাদের দাদাবাড়ির ছবি, ১৯৮৫ সালে তোলা।
ক্যাটাগরি: ছেলে / মেয়ে / অন্যান্য
ঠিকানা: বিশ্বনাথ, সিলেট
ছবি:
- https://i.imgur.com/abc123.jpg
- images/old-house-2.jpg
লিংক:
- সোর্স | https://example.com/article
- বিস্তারিত | https://example.com/more-info
```

ছবি বা লিংক না থাকলে ওই অংশ বাদ দিলেও চলবে।

## ভ্যালিডেশন — মেইলে পাওয়া ডেটা কীভাবে চেক করবে
`admin.html`-এ এখন এই সুবিধাগুলো আছে:
- মেইলের লেখাটা সরাসরি পেস্ট করলে ফর্ম অটো-ফিল হয়ে যায়
- প্রতিটা ছবির লিংকের পাশে ✓/✗ দেখাবে — লোড হচ্ছে কিনা তা যাচাই করে (রিলেটিভ পাথ যেমন `images/photo1.jpg` শুধু GitHub-এ আপলোডের পর ঠিকভাবে চেক হবে)
- বর্তমান `data.json` আপলোড করলে ডুপ্লিকেট অ্যাকসেশন নম্বর বা একই শিরোনাম থাকলে সতর্ক করবে, আর পরের অ্যাকসেশন নম্বর নিজে থেকেই বসিয়ে দেবে
- "JSON তৈরি করো" চাপলে শিরোনাম খালি থাকলে বা লিংক http/https দিয়ে শুরু না হলে আটকে দেবে

এরপরও মূল কাজটা তোমাকেই করতে হবে: বিবরণ পড়ে বুঝে নাও তথ্যটা ঠিক আছে কিনা, আপত্তিকর কিছু নেই তো, আর ছবি/লিংক প্রাসঙ্গিক কিনা — এই স্তরের যাচাই স্বয়ংক্রিয়ভাবে করা সম্ভব না, এটা তোমাকেই দেখতে হবে।
